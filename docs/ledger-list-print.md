# 거래내역 열 순서 및 리스트 출력

2026-11-09: 모든 테마가 공유하는 장부 거래내역의 마지막 두 열을 작업 → 작성자/수정일로 변경했다. 수정·삭제·이력 버튼 기능은 유지한다.

거래내역 제목 옆 ‘리스트 출력’은 현재 적용된 부서·기간·유형·계정·검색어·삭제 포함·정렬 조건의 전체 결과를 인쇄한다. 현재 페이지와 페이지 크기로 잘라 출력하지 않는다. 인쇄물은 A4 세로(좌우 3mm·상하 6mm, 본문 기본 여백 0), 흰 배경, 반복되는 표 제목, 부서·기간·조건·금액 합계·전체 부서 누적 잔액 기준 안내를 포함한다. 세로 용지 폭에 맞춘 고정 열 너비와 줄바꿈을 사용하며, 작업 버튼은 인쇄하지 않는다. 사용자는 브라우저 인쇄창에서 프린터 또는 PDF 저장을 선택한다.

`/api/transactions/print`는 기존 장부 읽기 경로의 부서 권한과 검증을 그대로 사용한다. HTML 출력에서 계정명·적요·비고·사용자명 등 문자열을 이스케이프하며 스크립트를 넣지 않는다. 응답은 no-store다. 클라이언트는 세션 범위 요청을 사용하고 계정·부서·조회 조건 변경을 확인한 뒤 스크립트가 허용되지 않는 인쇄 iframe에 표시한다. 로그아웃 시 프레임을 정리하고 출력 문서를 영구 저장하지 않는다.

장부 테스트 50개 및 타입·클라이언트·서버 빌드 통과. 추가 검사는 페이지 크기를 1로 요청해도 검색 결과 전체 2행을 출력하는지, 필터 합계와 부서 잔액을 혼동하지 않는지, 사용자 입력 HTML 이스케이프, 미인증·다른 부서 접근 차단 및 무변경 보장을 포함한다. 외부 DB 없는 임시 JSON 검수에서 변경된 열 순서, 출력 버튼, iframe 생성과 출력 후 버튼 복구, 브라우저 오류 없음도 확인했다. 실제 프린터로 용지를 출력하는 검수는 수행하지 않았다.

변경 파일: server/ledger.ts, server/ledger-print.ts, src/ledger.tsx, src/print.ts, tests/ledger.test.ts 및 이 문서. 기존 회계자료·저장 형식은 변경하지 않는다.
