# 이월금액 카드와 부서별 월별·연도별 관리

2026-11-06 사용자 추가 요청을 반영했습니다. 원본 명세를 변경하지 않고 조회 편의와 표시 항목을 확장했습니다.

## 변경 내용

- 대시보드와 장부의 합계 순서: **이월금액 → 수입 → 지출 → 차액 → 기간말 누적잔액**.
- 이월금액은 기초잔액 + 기초잔액 적용일부터 **조회 시작일 이전**까지의 활성 수입 − 활성 지출입니다. 조회 시작일의 거래는 이월에 포함하지 않습니다.
- 기초잔액이 없거나 적용일이 조회 시작일보다 늦으면 이월은 `—`로 표시합니다. 명시적인 0원·음수는 그대로 표시합니다.
- 장부의 검색어·계정·유형 필터는 이월과 기간말 잔액에 영향을 주지 않습니다. 카드의 안내 문구로 이를 구분합니다.
- 관리자 **부서·담당자 관리 → 수정 → 회계 관리 방식**에서 월별/연도별을 저장합니다. 부서 목록과 헤더에도 표시합니다.
- 월별: 해당 월 1일~말일 기본 조회, 연도·월 선택. 연도별: 1월 1일~12월 31일 기본 조회, 연도 선택. 장부의 시작/종료일을 직접 조정하는 기능도 유지합니다.
- 기존 설정 없는 부서는 월별로 읽어 기존 동작을 유지합니다. 새 부서 등록의 기본 선택은 연도별입니다. 구버전 클라이언트가 관리 방식을 생략한 PATCH는 기존 값을 유지합니다.
- 관리 방식 변경은 부서 설정과 감사이력만 변경합니다. 거래를 이동/복제/삭제하거나 기초잔액·마감을 변경하지 않습니다. 담당자가 옵션을 무단 수정할 수 없습니다.
- 대시보드의 합계 카드는 `/api/reports/summary`로 실제 원장에서 계산합니다. 특정 부서는 해당 부서 권한, 전체 부서 조회는 관리자 권한이 필요합니다. 전체 조회는 동일한 기간으로 합산하며 한 부서라도 잔액 미확정이면 부분 금액을 전체 잔액으로 표시하지 않습니다.
- 관리자 전체 부서 대시보드에서는 월별/연도별 조회 기준을 화면에서 선택합니다. 이 선택은 개별 부서 설정을 덮어쓰지 않습니다.
- 월별 차트와 통계 상세 화면은 이번 변경 범위에 포함하지 않았습니다. 대시보드의 미연결 안내를 현재 장부 연결 상태와 맞게 정리했습니다.

## 검증

- 전체 **120개 테스트 통과**: 기존 106개 + 이월/대시보드 권한 7개 + 옵션 저장/호환 2개 + 달력 경계 3개 + 초기 조회 화면 2개.
- 타입 검사·Vite production build·정적 산출물 검사 통과.
- 월말/연말 이월, 조회 첫날 거래 제외, 삭제 거래 제외, 검색 중 이월 보존, 0원·음수·미설정, 윤년/2100년 2월 검증.
- 실제 파일 재개방 후 옵션 유지, 기존 옵션 생략 PATCH 보존, 관리자 감사, 전체 부서 부분 잔액 오표시 방지 검증.
- 브라우저는 별도 임시 JSON에서 부서를 연도별로 변경하고 저장했습니다. 장부와 대시보드에 다섯 카드를 확인했습니다.
- 검증용 기초잔액 1,000,000원, 당해 수입 120,000원·지출 35,000원일 때 당해 이월 1,000,000원/기말 1,085,000원, 다음 해 이월 1,085,000원/기간 수입·지출 0원을 확인했습니다.
- 브라우저 확인 중 연도별 부서의 입력 날짜와 적용된 조회 기간 초기값 불일치를 발견해 수정하고 두 화면 회귀 테스트로 고정했습니다.
- 사용자 JSON의 부서 설정이나 거래를 임의로 바꾸지 않았습니다. 검증 화면의 금액은 격리된 가상 자료입니다.
