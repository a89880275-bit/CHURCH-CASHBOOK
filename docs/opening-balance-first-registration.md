# 기초잔액 담당자 최초 등록과 관리자 수정

2026-11-09 요청 반영.

- `/api/opening-balances` POST: 현재 배정된 활성 부서의 기초잔액이 없을 때 담당자가 최초 등록할 수 있다. 이미 있으면 0원이어도 담당자 재등록·수정을 403으로 차단한다. 관리자만 이후 수정할 수 있다.
- 기존 `/api/admin/opening-balances`는 관리자 전용 호환 경로로 유지한다. 새 경로도 기존 로그인·쓰기 검증·부서 권한 검사를 거친다.
- 저장 트랜잭션 안에서 사용자 활성 상태·현재 부서 배정·기초잔액 존재 여부를 다시 확인한다. 원자적 제어 행 잠금 후 검사하므로 동시 최초 등록은 한 건만 성공한다.
- 기존 적용일·정수 금액·버전·마감·거래일·잔액 계산 검증 및 감사이력을 유지한다. 관리자 수정 시 최초 등록자·등록 시각·ID를 유지한다.
- UI는 기초잔액이 없는 부서에 담당자의 설정 버튼을 표시하고 등록 후에는 숨긴다. 등록 전 최초 1회 제한을 안내하고 저장 성공 후 적용일·금액·관리자 수정 안내를 확인 모달 및 상태 메시지로 표시한다.
- 알림은 저장한 사용자 화면에 표시한다. 관리자에게 메일이나 외부 메시지를 보내는 기능은 추가하지 않는다.
- 기초잔액·거래·권한 자료의 마이그레이션이나 기존 금액 수정은 하지 않는다.

## 검증

장부 테스트 47개 및 독립 두 연결을 사용하는 격리 PostgreSQL 테스트 19개 통과. 템플릿/이월 집계 12개도 통과했다. 최초 0원 등록, 수정 거부 시 데이터 무변경, 관리자 수정, 비배정·중지 사용자 차단, 저장 직전 배정 해제, 두 연결의 동시 최초 저장 및 감사 보존을 포함한다. 최종 타입 검사와 클라이언트·서버 빌드 통과.

외부 DB와 연결하지 않은 OS 임시 폴더 JSON 검수 환경에서 담당자 로그인 → 최초 설정 → 120,000원 저장 → 적용일·금액·제한 안내 모달 → 확인 후 설정/수정 버튼 모두 0개를 확인했다. 검수 금액은 실제 Neon DB에 등록하지 않았다.
