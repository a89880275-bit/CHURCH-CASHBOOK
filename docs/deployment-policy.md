# 배포 정책 및 대기 목록

사용자 지시일: 2026-11-09.

## 작업 순서

개발 → 로컬 빌드·필요한 자동 테스트 → GitHub 저장 → 명시적 사용자 승인 → Netlify 배포.

코드 변경 뒤 자동 배포하지 않는다. 여러 기능을 모아 배포 대기 목록으로 관리한다. 실패한 배포는 자동 재시도하지 않는다. 배포가 차단되어도 개발·로컬 검증·GitHub 저장은 계속한다. GitHub 푸시 전에는 매번 자동 배포 연결을 재확인한다.

배포 전에는 대상 사이트·변경 목록·현재 남은 크레딧/사용량·예상 소모를 확인한다. 정확한 예상치를 제공하는 근거가 없으면 보장하지 않으며, 확인되지 않은 사용량을 충분하다고 가정하지 않는다. 설정된 인증·DB·서버 비밀키와 기존 회계자료를 유지한다.

## 자동 배포 연결 확인

2026-11-09 Netlify API로 테스트 사이트 cool-scone-571b5f를 읽기 전용 확인했다. build_settings의 저장소 URL/경로/ID/provider가 없으므로 현재 해당 사이트에 Netlify 저장소 기반 자동 배포가 연결된 것으로 확인되지 않는다. 로컬 .github/workflows 디렉터리도 없다. 외부에서 별도로 설정한 webhook 등은 이 확인만으로 배제하지 않는다. 이 관찰은 향후 연결 변경까지 보증하지 않으며 매 푸시 전 재확인한다.

자동 배포가 연결되면 Netlify의 자동 빌드 중지/저장소 연결 해제 또는 GitHub의 관련 배포 workflow 중지 방안을 현재 설정에 맞춰 안내하고, 승인 없이 설정을 바꾸거나 푸시하지 않는다.
